Adding a Form
to the Website

Four steps. You never need to read or understand the code — just copy, paste, and replace one line.

1

Get the code from iDSS

Build your form in iDSS as usual. When it's finished, iDSS gives you a block of code to embed.

Copy all of it. Every line, from top to bottom. Don't worry about what any of it says.

2

Add a Code Block in Squarespace

Go to the page where the form should live. Click to add a block, and choose Code.

Delete anything already inside it so the box is empty.

3

Paste this in first

Copy the three lines below and paste them into the empty Code Block.

paste this into the Code Block
<div class="tw-idss cols">
PASTE THE IDSS CODE HERE
</div>

Now highlight the words PASTE THE IDSS CODE HERE and paste the iDSS code over the top of them.

That's it. The first and last lines are always exactly the same for every form you ever add. Nothing in them ever changes.

4

Save, then check the live page

Save the page. Then open the real website — not the editing view.

The form will look blank or broken while you're editing. That's normal and expected. It only appears on the live site.

Three Rules

1️⃣
Only one iDSS form per page.

Two forms on the same page will not work — the second one silently stops working. If you need two forms, put them on two separate pages.

2️⃣
Changed the form in iDSS? Redo steps 1 and 3.

Any time you edit a form in iDSS — even adding one field — iDSS gives you brand-new code. The website keeps using the old code until you paste the new one in. Nothing warns you. The form just quietly stops collecting responses.

3️⃣
Always test on the live site after any change.

Fill the form out yourself and hit submit. Then check that it arrived in iDSS. Takes one minute and catches every problem on this page.

If Something Looks Wrong

The form isn't there at all

You're probably looking at the editing view. Save the page and open the real website in a new tab. If it's still missing, check that the first line <div class="tw-idss cols"> and the last line </div> are both there.

The form works but looks plain or wrong

The first or last line is missing or mistyped. Delete everything in the Code Block and redo step 3 from scratch. Don't try to fix it by hand.

The form stopped collecting responses

Someone edited it in iDSS. Go back to step 1, copy the fresh code, and redo step 3.

Fields run past the edge of the box

The site-wide styling isn't loaded. That's not something to fix in the Code Block — send it to Matt.

Want the fields side by side?

They already are, where there's room — and they stack automatically on phones. You don't have to do anything.

If you'd rather have one field per row, delete the word cols from the first line, so it reads <div class="tw-idss">.

The short version

Copy from iDSS → paste the 3 lines → replace the middle line → save → test on the live site.
